# 현재 아이템 이펙트 14종

2026년 10월 20일 연결된 Unity 프로젝트의 실제 소스 기준입니다. 아래는 현재 구현 목록이며, 이번 변경은 구명조끼의 손 모델 제거와 보호 이펙트 추가입니다. 다른 13종의 효과는 기존 구현을 정리했습니다.

## 복싱 글러브

양손 교대 펀치와 팔 뻗기·복귀. 피격 상대가 뒤로 밀리며 위로 뜹니다.

동작: 5m 근접, 2회 사용.

소스: Assets/Gameplay/GloveCombat.cs

## 압축 뚫어뻥

실제 뚫어뻥 모델이 전방으로 날아갔다 돌아옵니다. 적중한 상대를 앞으로 끌어옵니다.

동작: 최대 30m, 1회 사용.

소스: Assets/Gameplay/PlungerCombat.cs

## 뿅망치

망치 휘두르기와 피격 상대 머리 주변 회전 고리·어지럼 점. 본인 피격 시 화면 어지럼 표시.

동작: 3.5m 근접, 기절 5초, 1회.

소스: Assets/Gameplay/ToyHammerCombat.cs / DeliveryStunEffect.cs

## 슬라임

손 투척·초록 점액 탄, 표면 점액과 웅덩이. 피격 상대 몸의 점액 코팅·흘러내리는 방울과 본인 화면 감속 표시.

동작: 직격 감속 3초. 바닥 반경 3m, 유지 5초. 3회 사용.

소스: Assets/Gameplay/SlimeCombat.cs / SlimeSlowEffect.cs

## 아이스크림

손 투척·아이스크림 비행체, 적중 상대를 둘러싼 큰 얼음과 주변 결정. 본인 피격 시 서리 화면.

동작: 발사 전방 36m/s + 상승 3m/s, 빙결 3초, 1회.

소스: Assets/Gameplay/IceCreamCombat.cs / IceCreamFreezeEffect.cs

## 러닝화

손 모델 없이 사용. 몸 주변 하늘빛 바람 오라, 본인 화면 가장자리 바람선·맥동과 이동 중 시야각 변화.

동작: 이동 속도 +50% 5초, 1회.

소스: Assets/Gameplay/RunningShoesFX.cs

## 에어캡

손 모델 없이 사용. 몸 주변 비눗방울 보호막과 본인 화면의 반투명 방울, 방어 성공 시 파열 표시.

동작: 8초 안 유효 공격 1회 방어. 바닥 슬라임은 방어하지 않음. 1회 사용.

소스: Assets/Gameplay/BubbleWrapFX.cs

## 작업용 장갑

선택 중 작업용 장갑 손 모델과 우체통 점령 진행 HUD를 사용합니다. 별도 공격·발사 이펙트는 없습니다.

동작: 점령 3초 → 1.5초. 성공할 때 1회 소모.

소스: Assets/Gameplay/HeldItemPresentation.cs / MonsterDeliveryHUD.cs

## 만년필

손 투척·펜 비행과 잉크 궤적, 표면의 잉크 자국·비산 입자. 상대에게 잉크 피격 표시, 본인 화면에는 검은 잉크 시야 방해.

동작: 48m/s 직선, 최대 35m, 잉크 시야 방해 4초, 1회.

소스: Assets/Gameplay/FountainPenCombat.cs

## 공기 대포

발사 반동·공기 탄. 실제 충돌점에 순간 섬광, 공기 파편 28개와 입체 충격파 원 3개. 벽 충돌 방향을 따르며 0.65초 뒤 정리됩니다.

동작: 60m/s 직선, 최대 60m. 폭발 반경 6m, 본인 발밑 상승 가능. 1회.

소스: Assets/Gameplay/AirCannonCombat.cs / AirCannonImpactFX.cs

## 긴급 배송 방송기

수평 음파 3겹, 수직 반원 파동 2개, 회전 경고 원·방사형 음파 8줄, 주황 경고등과 금빛 불꽃 40개. 연출 1.3초.

동작: 12m 안 보이는 적 기절 4초. 1회.

소스: Assets/Gameplay/BroadcasterFX.cs / SpecialDeliveryItems.cs

## 원격 배송기

기존 모델과 노란 빔을 유지하며 우체통 점령 색상과 점수가 바뀝니다. 포장 상자와 기절을 제거했습니다.

동작: 18m 안 조준선의 첫 상대·중립 우체통을 좌클릭으로 즉시 점령합니다. 상대의 재점령 방지20초도 무시하며 점령 성공 후에는 새20초 보호를 적용합니다. 자기·아군 우체통, 벽·캐릭터 뒤, 사거리 밖 또는 빗나간 조준에는 소모하지 않습니다. 성공 시1회 사용 후 소모합니다. 기존 포장·기절 기능은 제거했습니다.

소스: Assets/Gameplay/SpecialDeliveryItems.cs / MonsterDeliveryPrototype.cs / DeliveryNetworkGameplay.cs

## 구명조끼

획득·선택 시 손 모델 없음. 사용 중 몸 주변 금빛 보호 링 3개와 움직이는 반짝임 8개, 조끼 표시. 본인은 금빛 화면 가장자리와 무적 남은 시간 HUD.

동작: 좌클릭 1회 소모, 5초간 새 방해 효과 면역. 기존 효과를 해제하지 않음.

소스: Assets/Gameplay/LifeJacketProtectionFX.cs / SpecialDeliveryItems.cs / HeldItemPresentation.cs

## 특급 배송 배터리

손에 든 배터리의 앞면 번개 로고가 플레이어를 향합니다. 사용 중 보라·청록 전기 아크 6개와 충전 회로 2개, 머리 위 배터리 아이콘과 차오르는 충전 칸 3개를 표시합니다. 본인은 화면 양옆의 번개·충전 칸과 전용 남은 시간 HUD를 봅니다. 러닝화의 바람과 별도이며 동시에 사용하면 각 이펙트가 독립적으로 표시됩니다.

동작: 8초 스태미나 무제한·이속 +30%. 러닝화와 겹치면 높은 배율만 적용. 1회.

소스: Assets/Gameplay/BatteryChargeFX.cs / RunningShoesFX.cs

## 이번 검증 범위

구명조끼는 실제 Unity Editor Play에서 15항목을 검사했습니다. 1·3인칭 손 모델 숨김, 1회 소모·5초 면역, 넉백·상승·기절·감속·잉크 및 비방어형 영역 차단, 에어캡 미소모, 이펙트 중복 방지·충돌 없음·종료 숨김과 면역 종료 후 피격 복귀를 통과했습니다. 다른 13종은 이번에 전체 동작을 재검사한 것이 아니라 현재 소스와 기존 구현을 정리했습니다.

별도 네트워크 두 프로세스·WAN·4인전·배포 실행 파일 재빌드는 이번에 수행하지 않았습니다. 기존 면역 잔여 시간 스냅샷을 재사용하고 프로토콜13을 유지합니다.
