# 아이템 UI와 1인칭 장착 표시

> 2026-10-15 현재 목록은 [GAME_DESIGN.md](../GAME_DESIGN.md)를 따른다. 무선 선풍기는 아이스크림(ID5)으로 교체했으며 아래 날짜별 제작·검수 내용은 당시 기록이다. 현재 아이스크림 모델/투척/빙결은 [변경 보고서](ChangeRecords/20261015/README.md)에 정리했다.

2026-10-08 · Unity 6000.5.10f1 · SampleScene

복싱 글러브와 작업용 장갑 슬롯 아이콘은 새 투명 배경 한 짝 PNG로 교체했다. 원본은 Assets/Art/DeliveryItemConcepts에 보존하고 Resources/UI/InGame에 복사한다. InGameUISetup.ImportItemIcons도 새 원본을 사용하므로 UI 재생성 시 유지된다. 3D 장갑은 기존 Blender에서 만든 좌우 한 쌍 모델을 사용한다.

Blender 산출물 중 복싱 글러브·압축 뚫어뻥·확성기·포장 테이프·무선 선풍기·작업용 장갑·프린터 잉크·미니 트램펄린 FBX를 Assets/Art/DeliveryItems/Models에 임포트했다. Resources/DeliveryItems 프리팹 8개와 공유 Standard 재질을 생성했다. 에어캡과 런닝화는 효과 전용으로 장착 모델을 표시하지 않는다.

HeldItemPresentation은 선택 종류/시점이 바뀔 때만 모델을 교체한다. 빈 슬롯·G 폐기·경기 종료 시 표시를 제거한다. 시작 인벤토리는 빈 상태다. itemPlaytestEnabled=false는 공격/효과 제한으로 유지하고 장착 표시를 별도로 허용한다.

1인칭은 아이템만 표시하고 장착 시 추가로 만들던 로봇 양팔/손은 제거했다. 3인칭 캐릭터의 원래 팔과 IDLE_ARMED/WALK_ARMED는 유지한다. 물건은 전방에 띄워 배치한다. 1인칭 장갑은 카메라 앞0.92m에서 올린 주먹 자세로 표시하며 다른 작은 아이템의 카메라 로컬 전방 위치는 1.20~1.25m, 큰 트램펄린은 1.70m와 75% 크기로 보정했다. 중앙 조준점과 시선 상호작용을 유지한다.

1인칭 물건은 기존에 비어 있던 레이어31과 Depth 클리어 전용 카메라로 그려 벽/지면에 가려지지 않게 한다. 주 카메라와 FOV/화면 비율을 공유하며 장착물 전용 무그림자 조명을 사용한다. Collider를 추가하지 않으므로 부유 몸통 충돌/상호작용 Raycast에 영향을 주지 않는다. 재질은 원색×0.8 기본 발광으로 새벽에도 읽히게 하고 Standard EmissiveIsBlack 플래그를 해제한다.

3인칭에서는 기존 팔/몸통 뼈를 따라 월드 표시한다. FBX의 좌우 좌표 변환을 실제 팔 위치로 구분하고 장갑은 좌우 팔에 독립 부착한다. 부착 위치는 IDLE_ARMED를 기준으로 손끝보다 앞으로 보정했다. 1인칭 복귀 시 전용 표시로 전환한다.

재생성: Edit Mode의 Tools/Gameplay/Held Items/Build Prefabs. 검수: Play Mode의 Tools/Gameplay/Held Items/Verify. 검수는 임시 아이템을 장착한 후 원래 슬롯과 시점을 복원한다.

검증 결과: 장착60, 실제 E/2/G 파밍39, 기존 UI15, 눈높이/부유 카메라15. Unity Console 오류0. 장착 검사에는 두 원본 아이콘 일치, 8종 화면 투영, 팔2개, 선택 캐시, 효과 전용2종, 실제2/G 입력, 3인칭 전환과 공격 게이트 유지가 포함된다.

두 장갑 효과 활성화 (2026-10-09 최신):
- 복싱 글러브 좌클릭은 양손을 당겼다 앞으로 밀고 되돌리는 Unity 절차 애니메이션(0.42초)이다. 1인칭 메시와 3인칭 팔뼈에 적용하고 기존 FBX/Blender 클립은 유지한다. 0.16초 타격 시점에 전방3m 원뿔/장애물 검사 후 넉백18·수직6을 기존 DeliveryItemState/CharacterController에 전달하며 상대 점령을 끊는다. 재사용0.6초, 빗나가도1회 소비, 마지막 충전은 복귀 후 제거한다. G/기절 중단 시 예약 타격을 취소한다.
