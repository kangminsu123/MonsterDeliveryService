## 맵 탐색 모드 정리 (2026-09-24)
- 사용자 요청: 맵 확인용으로 우편함/AI/임시 픽업을 빼고, 캐릭터에 배송 드론만 붙인 뒤 섬 위에서 시작.
- `MonsterDeliveryPrototype.mapExploreMode`를 기본 활성화. 탐색 모드에서는 `CreateWorld()`가 Player와 카메라 부착 저폴리 드론만 생성한 뒤 반환하므로 우편함, 라이벌 AI, 임시 무기/택배 픽업은 생성되지 않는다. 씬에 저장된 잔디/보도/도로/섬/Directional Light는 유지.
- 시작/리스폰 위치를 섬 중심 `(0,1,0)`으로 고정. 탐색 중 1번 드론 슬롯을 항상 유지하고 슬롯 전환/버리기/픽업 입력을 막는다. WASD+마우스로 맵 이동/시야 확인.
- Unity Play Mode 계층에서 런타임 생성 오브젝트가 MapExplorer, Main Camera(Attached Delivery Drone 자식 포함), Player뿐이고 Capture Pad/Rival/Mystery Parcel이 없는 것 확인. 플레이어 중심 위치 `(0, 약 0.92, 0)` 및 카메라 `(0, 약 2.55, 0)`가 섬 위임을 확인.
- Play Mode 재시작 후 Game 카메라에서 드론 모델 표시 및 축소된 크기 확인. 화면 오른쪽 아래에 붙어 맵을 크게 가리지 않는다. 최종 검증용 스크린샷은 프로젝트에 임시 파일로 남기지 않도록 제거.
- Unity MCP는 is_changing을 지연 표기했지만 Play Mode 재시작 후 계층/화면 응답은 정상. Hierarchy에 런타임 Player, Main Camera(Attached Delivery Drone 자식), MapExplorer만 확인.
- 탐색 모드 비행 입력 보완: 시작 시 드론 비행/호버 상태로 섬 중앙에서 2.5유닛 띄워 스폰. 마우스 좌클릭으로 착륙/재이륙 전환. 비행 중 WASD 이동, Space 상승, Left Ctrl 하강, 마우스로 시야 회전. 상단 작은 안내 표시. 이전 탐색 모드 입력 가드가 UseWeapon 호출까지 막았던 것이 비행되지 않던 원인.
- 콘솔 C# 오류/경고 없음. 이번 변경은 아직 커밋/푸시하지 않음.
